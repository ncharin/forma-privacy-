Politique de confidentialité

Conforme RGPD · Mise à jour : Avril 2026

Chez Forma, la protection de vos données personnelles est une priorité. Cette politique explique quelles données nous collectons, pourquoi, et comment vous pouvez exercer vos droits.

1. Responsable du traitement

Forma est éditée par Charin Nicolas, nicolascharin13@gmail.com. En utilisant Forma, vous acceptez la présente Politique de Confidentialité.

2. Données collectées

Nous collectons les données suivantes :

  • Profil : prénom, sexe, date de naissance, taille, poids, niveau d'activité
  • Entraînements : séances, exercices, séries, poids, répétitions
  • Nutrition : journaux alimentaires, objectifs caloriques
  • Récupération : sommeil, blessures, humeur
  • Cardio : sessions, distance, durée, calories
  • Corps : mesures corporelles, objectif de poids
  • Données techniques : version de l'app, système d'exploitation (sans identifiant publicitaire)

Nous ne collectons pas de données de localisation GPS ni de contacts téléphoniques.

3. Finalités du traitement

  • Personnaliser votre expérience (calcul TDEE, macros, programmes)
  • Afficher vos statistiques et progressions
  • Synchroniser vos données entre appareils (si Supabase activé)
  • Améliorer l'Application (données anonymisées uniquement)

4. Base légale (RGPD)

  • Exécution du contrat : fourniture des services demandés
  • Intérêt légitime : amélioration de l'application
  • Consentement : fonctionnalités optionnelles (notifications, partage social)

5. Stockage et sécurité

  • Par défaut, toutes vos données sont stockées localement sur votre appareil
  • Si vous activez la synchronisation cloud, les données sont stockées sur Supabase (hébergé en Europe, conforme RGPD)
  • Nous appliquons des mesures de sécurité techniques et organisationnelles pour protéger vos données

6. Partage des données

Nous ne vendons jamais vos données à des tiers. Vos données peuvent être partagées avec :

  • Supabase (stockage cloud, optionnel) — supabase.com/privacy

La fonctionnalité sociale vous permet de choisir explicitement ce que vous partagez avec vos amis.

7. Vos droits (RGPD)

  • Accès : bouton "Exporter mes données" dans Réglages
  • Rectification : modifier vos données dans l'application
  • Effacement : bouton "Supprimer mes données" dans Réglages
  • Portabilité : exporter vos données au format JSON
  • Opposition : désactiver les fonctionnalités de collecte optionnelles
  • Réclamation : contacter la CNIL

Contact : nicolascharin13@gmail.com

8. Conservation des données

  • Données locales : conservées jusqu'à désinstallation ou suppression manuelle
  • Données cloud : conservées pendant la durée du compte, puis supprimées dans les 30 jours suivant la résiliation

9. Mineurs

Forma est destinée aux personnes de 16 ans et plus. Nous ne collectons pas sciemment de données concernant des mineurs de moins de 16 ans.

10. Modifications

Nous pouvons mettre à jour cette politique. Vous serez informé(e) par notification en cas de changement significatif.
